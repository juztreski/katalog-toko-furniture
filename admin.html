Buka Google Sheets Lihat Katalog

Produk dikelola langsung di Google Sheets. Ubah data di spreadsheet lalu simpan — perubahan langsung tampil di situs saat pengunjung membuka halaman. Foto dapat berupa nama file di images/produk/ atau URL gambar eksternal (pisahkan dengan koma).

Belum dihubungkan ke Google Sheets. Cara menghubungkan:

  1. Buat sheet di sheets.new dengan baris pertama: id | nama | kategori | harga | stok | deskripsi | foto
  2. File → Share → "Anyone with the link" → Viewer → salin link
  3. Ubah link jadi https://docs.google.com/spreadsheets/d/<ID_SHEET>/export?format=csv&gid=0
  4. Tempel ke js/config.js (baris window.SHEET_URL = "...")
  5. Commit & push — selesai, update berikutnya cukup lewat spreadsheet
